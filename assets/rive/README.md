# Bundled Rive example skin

`Zombie_Character.riv` comes from the official Rive Flutter example repository
at commit `9bb8f7f4a06db6c1472eb073eb39837ea2a81a86` and is distributed under the
MIT license in `LICENSE.txt`.

Upstream file:
https://github.com/rive-app/rive-flutter/blob/9bb8f7f4a06db6c1472eb073eb39837ea2a81a86/example/assets/perf/rivs/Zombie_Character.riv

The character is intentionally a coarse demonstration rig. Use
`zombie-kimodo-map.json` with the **Kimodo Render Rive Skinned Character** node,
or leave both path fields on their `builtin:` defaults.
